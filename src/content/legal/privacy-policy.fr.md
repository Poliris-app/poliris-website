## 1. Données que nous collectons

### 1.1 Lorsque vous visitez le Site

Nous pouvons traiter :

- des données techniques, telles que l'adresse IP, le type et la version du navigateur, le type d'appareil, les pages consultées, le site référent et des données de journalisation similaires, notamment afin d'assurer le fonctionnement, la sécurité et la protection du Site ;
- les données que vous nous transmettez volontairement, telles que votre nom, votre adresse e-mail, le nom de votre entreprise et le contenu de votre message lorsque vous utilisez un formulaire de contact ou demandez une démonstration.

Des données relatives à votre utilisation du Site peuvent également être traitées par des outils de mesure d'audience lorsque ceux-ci sont activés, dans les conditions décrites à la section 12.

### 1.2 Lorsque vous créez et utilisez un compte Poliris

Nous pouvons traiter :

- les données de compte : nom, adresse e-mail professionnelle, mot de passe sous forme hachée, entreprise et informations associées à votre compte ;
- les informations de facturation nécessaires à la gestion de votre abonnement et de vos paiements ;
- les données d'utilisation du Service : actions effectuées dans l'interface, projets et sites configurés, paramètres, historique des opérations et échanges avec le support ;
- les données de contenu : domaines, URL, mots-clés, prompts et contenus web que vous demandez à Poliris d'auditer, d'analyser ou de traiter.

Les audits de sites peuvent impliquer l'exploration automatisée de pages publiquement accessibles des domaines que vous configurez. Cette exploration fonctionne indépendamment du Plugin WordPress.

Les contenus publics analysés peuvent occasionnellement contenir des données à caractère personnel. Lorsque vous nous demandez de traiter des données concernant des tiers, il vous appartient de vous assurer que vous disposez d'une base juridique appropriée pour ce traitement.

### 1.3 Lorsque vous utilisez le Plugin WordPress

Le Plugin constitue un connecteur entre votre site WordPress et votre compte Poliris.

Lors de l'appairage d'un site WordPress, le Plugin peut transmettre à Poliris, via une connexion sécurisée :

- un mot de passe d'application WordPress associé au compte utilisé pour l'appairage ;
- le code d'appairage ;
- l'URL du site ;
- le nom d'utilisateur WordPress de l'administrateur effectuant l'appairage ;
- la version de WordPress ;
- la version du Plugin ;
- le nom du plugin SEO actif, le cas échéant.

Une fois le site appairé, Poliris peut communiquer avec celui-ci par l'intermédiaire de l'API REST de WordPress.

Lorsque vous approuvez explicitement une modification dans le tableau de bord Poliris, Poliris peut notamment transmettre à votre site le contenu nécessaire à son application, par exemple :

- un titre ;
- une meta description ;
- du contenu de page ;
- un texte alternatif d'image ;
- un nouvel article créé sous forme de brouillon.

Le Plugin peut également effectuer des communications techniques nécessaires au maintien de la connexion avec Poliris, notamment afin de récupérer les modifications approuvées ou de signaler l'état de la connexion.

Ces communications peuvent utiliser un identifiant technique propre au site et un horodatage.

### 1.4 Lorsque vous utilisez Poli IA

Le Service peut mettre à votre disposition un assistant conversationnel appelé Poli IA.

Lorsque vous utilisez Poli IA, nous pouvons traiter :

- le contenu de vos conversations, comprenant vos messages, questions, instructions et les réponses générées ;
- des informations contextuelles nécessaires à la réponse, par exemple les données du projet ou du site sur lequel porte votre question ;
- des données techniques, telles que l'horodatage et l'identifiant de la session.

Les conversations peuvent contenir des données personnelles lorsque vous choisissez d'en communiquer. Nous vous recommandons de ne transmettre que les informations nécessaires à votre demande et de ne pas communiquer de données sensibles ou confidentielles qui ne seraient pas nécessaires.

Certaines informations nécessaires à la génération d'une réponse peuvent être transmises à nos fournisseurs de modèles d'intelligence artificielle dans les conditions décrites aux sections 3 et 4.

L'interface de Poli IA indique à l'utilisateur qu'il interagit avec un système d'intelligence artificielle.

### 1.5 Lorsque vous connectez Google Analytics ou Google Search Console

Vous pouvez choisir de connecter une propriété Google Analytics 4 et/ou Google Search Console à un site configuré dans Poliris.

Cette connexion est facultative et est initiée par vous au moyen du mécanisme d'autorisation fourni par Google.

Poliris demande uniquement les autorisations nécessaires aux fonctionnalités proposées, notamment :

- `https://www.googleapis.com/auth/analytics.readonly` ;
- `https://www.googleapis.com/auth/webmasters.readonly` ;
- les informations d'identification du compte Google nécessaires à la connexion, notamment `openid` et `email`.

Ces autorisations sont en lecture seule.

Lorsque vous connectez Google Search Console, Poliris peut notamment lire les informations de performance associées à la propriété sélectionnée, telles que :

- requêtes ;
- pages ;
- clics ;
- impressions ;
- taux de clic ;
- position moyenne ;
- appareil ;
- pays.

Lorsque vous connectez Google Analytics 4, Poliris peut notamment lire certaines données de rapport relatives à la propriété sélectionnée, telles que :

- sessions et canaux d'acquisition ;
- utilisateurs ;
- caractéristiques agrégées d'audience disponibles dans votre propriété ;
- type d'appareil et pays ;
- métriques d'engagement ;
- performances agrégées des pages auditées.

Poliris n'utilise pas ces autorisations pour modifier ou supprimer des données dans votre propriété Google Analytics ou Google Search Console.

L'utilisation spécifique des données reçues des API Google est détaillée à la section 7.

### 1.6 Données de prospects professionnels

Dans le cadre de notre activité commerciale, nous pouvons traiter des informations professionnelles relatives à des personnes susceptibles d'être intéressées par Poliris.

Ces informations peuvent notamment comprendre :

- prénom et nom ;
- fonction professionnelle ;
- entreprise ;
- coordonnées professionnelles ;
- site internet de l'entreprise ;
- informations professionnelles pertinentes pour déterminer l'intérêt potentiel de Poliris.

Ces données peuvent provenir :

- de sources professionnelles publiquement accessibles ;
- du site internet de votre entreprise ;
- de réseaux ou annuaires professionnels ;
- de prestataires spécialisés dans l'identification de contacts professionnels, tels qu'Apollo ;
- de nos interactions antérieures avec vous ou votre entreprise.

Lorsque les données n'ont pas été collectées directement auprès de vous, nous vous informons de leur utilisation au plus tard lors de notre première communication avec vous ou dans les délais prévus par la réglementation applicable.

Chaque communication de prospection permet de vous opposer facilement à toute nouvelle sollicitation.

### 1.7 Ce que le Plugin ne collecte pas

Dans son fonctionnement normal, le Plugin Poliris n'a pas pour objet de collecter ou transmettre à Poliris les données personnelles des visiteurs de votre propre site.

Il ne transmet notamment pas à Poliris, du seul fait de son installation :

- les adresses IP de vos visiteurs ;
- leurs cookies ;
- leur historique de navigation ;
- leurs données clients ou de commerce électronique ;
- leurs données analytiques.

Le Plugin n'a pas non plus pour objet de déposer des cookies de suivi sur le navigateur de vos visiteurs.

Ces déclarations concernent le Plugin Poliris lui-même et non les autres extensions, services ou outils que vous pourriez utiliser sur votre site WordPress.

## 3. Utilisation de l'intelligence artificielle

Poliris utilise des modèles et services d'intelligence artificielle afin notamment de :

- analyser des sites et leur visibilité ;
- produire des recommandations ;
- générer ou améliorer certains contenus ;
- répondre aux utilisateurs de Poli IA.

Dans ce cadre, Poliris peut transmettre à un fournisseur d'intelligence artificielle les informations strictement nécessaires à l'exécution de la fonctionnalité demandée.

### Entraînement des modèles

Poliris n'utilise pas les données personnelles de ses clients, leurs conversations ou leurs données Google afin d'entraîner ses propres modèles d'intelligence artificielle généralistes.

Lorsque nous utilisons des fournisseurs d'intelligence artificielle via leurs offres professionnelles ou leurs API, nous privilégions et configurons, lorsque cela est applicable, les services pour lesquels les données transmises dans le cadre de l'utilisation de l'API ne servent pas à entraîner les modèles généralistes du fournisseur sans action ou autorisation spécifique de notre part.

Poliris n'active volontairement aucun mécanisme permettant l'utilisation du contenu client à des fins d'entraînement général des modèles de ses fournisseurs.

Cette absence d'utilisation pour l'entraînement n'exclut pas les éventuelles conservations techniques temporaires mises en œuvre par un fournisseur pour la sécurité, la prévention des abus ou le respect de ses obligations légales, conformément aux conditions applicables à son service.

### Données Google

Les données provenant des API Google font l'objet des garanties supplémentaires prévues à la section 7.

- une décision d'adéquation de la Commission européenne ;
- le cadre de protection des données UE–États-Unis (« EU-U.S. Data Privacy Framework ») lorsque le destinataire est valablement certifié et que ce mécanisme est applicable au transfert concerné ;
- les clauses contractuelles types de la Commission européenne ;
- ainsi que, lorsque cela est nécessaire, des mesures complémentaires appropriées.

Lorsqu'un prestataire est établi au Royaume-Uni, les transferts peuvent notamment reposer sur la décision d'adéquation applicable, sous réserve de son maintien et de son champ d'application.

Le fait que les données principales de Poliris soient stockées dans l'Union européenne ne signifie donc pas qu'aucun traitement ou accès technique ne puisse avoir lieu en dehors de l'Union européenne.

Vous pouvez nous contacter afin d'obtenir davantage d'informations concernant les garanties applicables à un transfert particulier.

## 7. Données provenant des API Google

La présente section concerne spécifiquement les informations reçues de Google Analytics et Google Search Console lorsque vous choisissez de connecter ces services à Poliris.

### 7.1 Utilisation

Nous utilisons ces données uniquement pour fournir les fonctionnalités Poliris associées au site que vous avez connecté.

- afficher les performances du site ;
- compléter des audits techniques ;
- compléter des audits de mots-clés ;
- produire des indicateurs ;
- répondre à une question portant sur votre site dans Poli IA lorsque vous sollicitez cette fonctionnalité.

### 7.2 Accès et permissions

Nous demandons uniquement les autorisations nécessaires au fonctionnement des fonctionnalités activées.

Les accès Google Analytics et Google Search Console utilisés par Poliris sont en lecture seule.

### 7.3 Utilisation dans Poli IA

Lorsque vous demandez à Poli IA d'analyser ou d'expliquer des données provenant d'une intégration Google, les éléments nécessaires à cette réponse peuvent être transmis au fournisseur d'intelligence artificielle utilisé pour générer la réponse.

Ce traitement intervient uniquement dans le cadre de la fonctionnalité Poliris que vous utilisez et à la suite de votre action.

Poliris ne transmet pas les données provenant des API Google à un fournisseur d'IA pour entraîner ou améliorer un modèle d'intelligence artificielle généraliste.

Le jeton d'actualisation Google permettant de maintenir la connexion est protégé au repos sur notre infrastructure.

### 7.5 Partage et utilisations interdites

Poliris :

- ne vend pas les données provenant des API Google ;
- ne les utilise pas pour diffuser de la publicité ciblée ou personnalisée ;
- ne les utilise pas à des fins de reciblage publicitaire ;
- ne les utilise pas pour déterminer une solvabilité ou prendre une décision de prêt ;
- ne les utilise pas pour développer ou entraîner un modèle d'intelligence artificielle généraliste ;
- ne les transmet pas à des courtiers en données ou à des revendeurs d'informations.

Elles ne peuvent être communiquées qu'aux prestataires nécessaires à la fourniture de la fonctionnalité demandée, à la sécurité du Service, au respect de la loi ou à une opération juridique autorisée, dans les limites permises par les règles applicables.

L'utilisation et le transfert par Poliris vers toute autre application des informations reçues des API Google respecteront la [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), y compris les exigences d'utilisation limitée (Limited Use).

### 7.6 Accès humain

Notre personnel n'accède aux données provenant de vos intégrations Google que lorsque cela est nécessaire et autorisé, notamment :

- à votre demande pour vous assister ;
- pour résoudre un problème technique ;
- pour assurer la sécurité du Service ou enquêter sur un abus ;
- pour respecter une obligation légale ;
- lorsque les données ont été agrégées ou anonymisées de manière à ne plus identifier une personne.

Les personnes disposant d'un accès sont soumises à des obligations de confidentialité et à des restrictions d'accès.

Vous pouvez déconnecter Google Analytics ou Google Search Console depuis les paramètres disponibles dans Poliris.

La déconnexion entraîne la suppression du jeton permettant à Poliris de maintenir l'accès à la propriété concernée, selon le fonctionnement prévu par le Service.

## 9. Durées de conservation

Nous ne conservons les données personnelles que pendant la durée nécessaire à la finalité pour laquelle elles sont traitées, sous réserve des obligations légales applicables.

### Comptes et données du Service

Les données actives du compte sont conservées pendant la durée de la relation contractuelle.

Après la clôture du compte, elles sont supprimées ou anonymisées dans un délai maximal de 90 jours, sauf lorsqu'une conservation plus longue est nécessaire pour respecter une obligation légale, résoudre un litige ou défendre nos droits.

Les copies présentes dans les sauvegardes peuvent subsister pendant une durée supplémentaire limitée avant leur purge selon le cycle normal de sauvegarde.

### Données du Plugin WordPress

Les informations d'authentification conservées par Poliris pour accéder à un site WordPress sont supprimées lorsque la connexion du site à Poliris est supprimée dans les conditions prévues par le Service.

Vous pouvez également révoquer directement le mot de passe d'application depuis WordPress. Une fois révoqué dans WordPress, celui-ci ne peut plus être utilisé par Poliris.

La simple désactivation du Plugin ne doit pas être considérée comme un substitut à la révocation du mot de passe d'application lorsque vous souhaitez supprimer définitivement l'autorisation.

### Intégrations Google

Les autorisations conservées par Poliris sont supprimées lorsque vous déconnectez l'intégration correspondante.

Les données de rapport déjà importées suivent la durée de conservation du projet ou de l'audit auquel elles sont rattachées.

### Facturation et comptabilité

Les documents devant être conservés au titre des obligations comptables, fiscales ou commerciales sont conservés pendant la durée imposée par la réglementation applicable, pouvant notamment atteindre 10 ans.

### Journaux techniques et de sécurité

Les journaux techniques et de sécurité sont conservés pendant une durée proportionnée à leur finalité et, sauf nécessité particulière, pendant une durée maximale de 12 mois.

### Demandes de contact

Les données relatives à une demande de contact qui ne donne pas lieu à une relation contractuelle sont conservées pendant une durée maximale de 24 mois à compter du dernier échange utile, sauf nécessité justifiant une durée inférieure ou supérieure.

### Prospects professionnels

Les données utilisées à des fins de prospection concernant une personne qui n'est pas cliente sont conservées pendant une durée maximale de 3 ans à compter de leur collecte ou du dernier contact émanant du prospect.
