## Keeping them current

The **Last captured** column is the date each file last changed in git, which is
the best record we have of when the screen was photographed.

Add this to the release checklist: when a release changes a screen, re-capture
its screenshot in the same pass and commit it, so the date moves with it. The
chapter column says which page each shot belongs to.
